## Условие

Буквы $a, b, c, d$ — термины (субъекты и одноместные предикаты); $x, y$ — высказывания. Каким аксиомным схемам $S^s_{cq}$ (с. 99) соответствуют формулы?

а) $(d \leftarrow b) \vdash (\exists b)(d \leftarrow b)$
б) $(\forall b)(a \leftarrow c) \vdash \sim (\exists b)\sim (a \leftarrow c)$
в) $(\forall b)(d \leftarrow b)(\exists b)(b \leftarrow d) \vdash (\exists b)((d \leftarrow b)(b \leftarrow d))$
г) $(\forall a)(c \leftarrow b) \vdash (c \leftarrow b)$

## Ответ

а) A2; б) A6; в) A3; г) A1

## Решение

A2: $x \vdash (\exists a)x$; A6: $(\forall a)x \vdash \sim(\exists a)\sim x$; A3: $(\forall a)x(\exists a)y \vdash (\exists a)(xy)$; A1: $(\forall a)x \vdash x$.

## Решение

С. 138–139: $a \rightharpoonup b$ читается «$b$ есть $a$».

## Условие

Буквы $a, b, c$ — термины. Укажите номера следствий $S^2_t$ (с. 142–143):

а) $\vdash \sim(a \leftarrow b) \to \sim(a \leftarrow bc)$
б) $\vdash (a \urcorner\!\leftarrow b) \vee (a \urcorner\!\leftarrow c) \to (a \urcorner\!\leftarrow bc)$
в) $\vdash \sim((a \leftarrow b)(a \leftarrow \tilde b))$

## Ответ

а) T5; б) T2; в) T11

## Решение

Для каждой формулы ищем схему, из которой она получается заменой метапеременных (одинаковые буквы схемы — одинаковыми выражениями).

а) Схема T5: $\vdash \sim(a \leftarrow b) \to \sim(a \leftarrow bc)$. Формула получается из неё без замены букв.
б) Схема T2: $\vdash (a \urcorner\!\leftarrow b) \vee (a \urcorner\!\leftarrow c) \to (a \urcorner\!\leftarrow bc)$. Формула получается из неё без замены букв.
в) Схема T11: $\vdash \sim((a \leftarrow b)(a \leftarrow \tilde b))$. Формула получается из неё без замены букв.

Схемы — с. 142–143.

## Условие

Буква $x$ — высказывание с главным оператором $\leftarrow$ (например, $a \leftarrow b$); $\urcorner x$ и $?x$ — по дополнению к определению высказывания (гл. 5, § 5, с. 76). Главная интерпретация (с. 76): если одно из $x$ и $\urcorner x$ имеет значение 1, другое — 0; если одно имеет значение 0, значение другого от него не зависит; $?x$ равнозначно $\sim x\sim\urcorner x$. Какие формулы — тавтологии?

а) $x \vdash \sim ?x$
б) $\sim x \vdash \urcorner x$
в) $x \vdash \sim \urcorner x$
г) $\sim \urcorner x \vdash x$

## Ответ

а) да; б) нет; в) да; г) нет

## Решение

Из трёх высказываний $x$, $\urcorner x$, $?x$ истинно ровно одно. Перебираем три случая.

Источник: с. 76–77, гл. 5, § 5.

## Условие

Буквы $a, b, c, d$ — термины (субъекты и одноместные предикаты); $x, y$ — высказывания. В $S^s$ доказуема $(a \leftarrow d)(a \leftarrow c) \vdash (a \leftarrow c)(a \leftarrow d)$. Что даёт правило R1 системы $S^s_{cq}$ с термином $a$ (с. 100)?

## Ответ

$(\forall a)((a \leftarrow d)(a \leftarrow c)) \vdash (\forall a)((a \leftarrow c)(a \leftarrow d))$

## Решение

R1: если $x \vdash y$, то $(\forall a)x \vdash (\forall a)y$; R2: если $x \vdash y$, то $(\exists a)x \vdash (\exists a)y$.
