## Условие

Буквы $x, y, z, u, w$ — элементарные высказывания; запись по соглашению книги (с. 15). Подставьте в аксиомную схему A10 ($xy : \sim x \sim y \vdash \sim(x : y)$) вместо $x$ — $uw$, $y$ — $y$ и запишите полученную аксиому.

## Ответ

$(uw)y : \sim(uw)\sim y \vdash \sim(uw : y)$

## Решение

Схема A10 — с. 16. Подставляем и расставляем скобки по соглашению книги: составной член конъюнкции, если он дизъюнкция или конъюнкция, берётся в скобки; отрицание составного высказывания — $\sim(\dots)$.

## Условие

Буквы $x, y, z, u$ — элементарные высказывания; запись по соглашению книги (с. 15). Для каждой формулы выпишите элементарные высказывания, которые входят в заключение, но не входят в посылку.

а) $y(\sim z : y)\sim z \vdash (z\sim y)(\sim x : x)$
б) $x \vdash (\sim u : \sim x) : \sim u$
в) $(x : \sim x)\sim z \vdash (x\sim z)\sim u$
г) $(y : \sim y : \sim z) : \sim y\sim x : yz \vdash z : \sim x$
д) $\sim z \vdash \sim z$

## Ответ

а) $x$; б) $u$; в) $u$; г) нет; д) нет

## Решение

По § 4, MT1 (с. 21) формулы, где такие высказывания есть, недоказуемы в $S^1$.

## Условие

Буквы $x, y, z, u, w$ — элементарные высказывания; запись по соглашению книги (с. 15). Вычислите при главной интерпретации значения высказываний при $x = 0$, $y = 1$, $z = 1$.

а) $(y : \sim x) : (z : \sim zz)$
б) $(\sim x : (z : y))\sim(\sim x : \sim z)$
в) $\sim z$
г) $\sim y : (y : z)$
д) $(x(x : \sim x))(\sim y : \sim x)$

## Ответ

а) 1; б) 0; в) 0; г) 0; д) 0

## Решение

Пункты 2–4 главной интерпретации (с. 22): $\sim$ меняет значение; конъюнкция имеет значение 1, когда все члены — 1; $x^1 : \ldots : x^n$ — когда одно и только одно из $x^i$ имеет значение 1. Значения вычисляются от элементарных высказываний к целому.

## Условие

Буквы $x, y, z, u, w$ — элементарные высказывания; запись по соглашению книги (с. 15). Студент рассуждает: «В заключение каждой из этих формул не входят элементарные высказывания, отсутствующие в посылке. Значит, по § 4, MT1 все они доказуемы в $S^1$». Найдите ошибку и укажите, какие формулы на самом деле недоказуемы.

а) $x\sim x : \sim y \vdash x$
б) $y\sim x \vdash x$
в) $(x : y) : y \vdash y\sim x : \sim x$
г) $\sim x : \sim x\sim y \vdash (x : \sim y)(\sim y : y)$

## Ответ

MT1 — необходимое условие доказуемости, а не достаточное. Недоказуемы: а), б), в), г).

## Решение

MT1 (с. 21): если $x \vdash y$ — теорема, то в $y$ нет новых элементарных высказываний; обратное не утверждается. Недоказуемые формулы не тавтологии (§ 5, MT1, с. 22):
- а) при $x = 0$, $y = 0$ посылка — 1, заключение — 0.
- б) при $x = 0$, $y = 1$ посылка — 1, заключение — 0.
- в) при $x = 1$, $y = 0$ посылка — 1, заключение — 0.
- г) при $x = 0$, $y = 1$ посылка — 1, заключение — 0.

## Условие

Буквы $x, y, z, u, w$ — элементарные высказывания; запись по соглашению книги (с. 15). В выводе формулы $\sim \sim(x\sim z) \vdash \sim z$ ровно в одном шаге неверно указано основание. Найдите шаг и исправьте.

1. $\sim \sim(x\sim z) \vdash x\sim z$ [A2]
2. $x\sim z \vdash \sim zx$ [A4]
3. $\sim \sim(x\sim z) \vdash \sim zx$ [R1: 1, 2]
4. $\sim zx \vdash \sim z$ [A2]
5. $\sim \sim(x\sim z) \vdash \sim z$ [R1: 3, 4]

## Ответ

Шаг 4: верно — A3.

## Решение

Проверяем каждый шаг по аксиомным схемам (с. 15–17) и правилам (с. 17). Верный вывод:

1. $\sim \sim(x\sim z) \vdash x\sim z$ [A2]
2. $x\sim z \vdash \sim zx$ [A4]
3. $\sim \sim(x\sim z) \vdash \sim zx$ [R1: 1, 2]
4. $\sim zx \vdash \sim z$ [A3]
5. $\sim \sim(x\sim z) \vdash \sim z$ [R1: 3, 4]

## Условие

Буквы $x, y, z, u, w$ — элементарные высказывания; $\vee$ — соединительная дизъюнкция («по крайней мере одно из», гл. 2, § 1, с. 36); запись — по соглашению книги. Восстановите пропущенные основания вывода в $S_1$.

1. $(u \vee w)(uw) \vdash (uw)(u \vee w)$ […]
2. $(uw)(u \vee w) \vdash (u \vee w)(uw)$ […]
3. $\sim((u \vee w)(uw)) \vdash \sim((uw)(u \vee w))$ [R3: 1, 2]

## Ответ

1 — A4; 2 — A4

## Решение

1. $(u \vee w)(uw) \vdash (uw)(u \vee w)$ [A4]
2. $(uw)(u \vee w) \vdash (u \vee w)(uw)$ [A4]
3. $\sim((u \vee w)(uw)) \vdash \sim((uw)(u \vee w))$ [R3: 1, 2]

Правила R1–R3 — как в $S^1$ (с. 17, 36).
