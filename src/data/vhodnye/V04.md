## Условие

Буквы $x, y, z, u$ — элементарные высказывания; запись по соглашению книги (с. 15). Для каждой формулы выпишите элементарные высказывания, которые входят в заключение, но не входят в посылку.

а) $(z : \sim x) : \sim y \vdash (\sim y : \sim z)(\sim u : z : u)$
б) $\sim z(z : x) \vdash \sim(z : y)$
в) $\sim z : x \vdash \sim x : \sim u$
г) $\sim z : x \vdash (zu)\sim x$
д) $(z\sim z)x\sim x \vdash (yz)x$

## Ответ

а) $u$; б) $y$; в) $u$; г) $u$; д) $y$

## Решение

По § 4, MT1 (с. 21) формулы, где такие высказывания есть, недоказуемы в $S^1$.

## Условие

Буквы $x, y, z, u, w$ — элементарные высказывания; запись по соглашению книги (с. 15). Вычислите при главной интерпретации значения высказываний при $x = 1$, $y = 0$, $z = 0$.

а) $(\sim zz : \sim y : y)(\sim x : y)$
б) $\sim x(\sim y : \sim x) : \sim y$
в) $((\sim zx)(yx))(x\sim x : \sim x)$
г) $\sim((\sim z : z)(y : x))$
д) $\sim(z : \sim x)$

## Ответ

а) 0; б) 1; в) 0; г) 0; д) 1

## Решение

Пункты 2–4 главной интерпретации (с. 22): $\sim$ меняет значение; конъюнкция имеет значение 1, когда все члены — 1; $x^1 : \ldots : x^n$ — когда одно и только одно из $x^i$ имеет значение 1. Значения вычисляются от элементарных высказываний к целому.

## Условие

Буквы $x, y, z, u, w$ — элементарные высказывания; запись по соглашению книги (с. 15). Студент рассуждает: «В заключение каждой из этих формул не входят элементарные высказывания, отсутствующие в посылке. Значит, по § 4, MT1 все они доказуемы в $S^1$». Найдите ошибку и укажите, какие формулы на самом деле недоказуемы.

а) $(yx)\sim x \vdash \sim(\sim x : y)$
б) $\sim(x\sim y) \vdash (x : \sim y)(x : \sim x)\sim x$
в) $x \vdash x$
г) $\sim x : \sim yy \vdash x$

## Ответ

MT1 — необходимое условие доказуемости, а не достаточное. Недоказуемы: б), г).

## Решение

MT1 (с. 21): если $x \vdash y$ — теорема, то в $y$ нет новых элементарных высказываний; обратное не утверждается. Недоказуемые формулы не тавтологии (§ 5, MT1, с. 22):
- б) при $x = 0$, $y = 1$ посылка — 1, заключение — 0.
- г) при $x = 0$, $y = 0$ посылка — 1, заключение — 0.

## Условие

Буквы $x, y, z, u, w$ — элементарные высказывания; запись по соглашению книги (с. 15). Студент проверил формулу $(y : \sim y : \sim x) : y\sim xx \vdash (xy)(y\sim y)$: «при $x = 1$, $y = 0$ посылка имеет значение 1, заключение — 0, значит, формула имеет значение 1; так при всех значениях — тавтология». Найдите ошибку.

## Ответ

При этих значениях формула имеет значение 0 (посылка 1, заключение 0), поэтому она не тавтология.

## Решение

Главная интерпретация, п. 5 (с. 22): $x \vdash y$ имеет значение 0 тогда и только тогда, когда $x$ имеет значение 1, а $y$ — 0. D1 (с. 22): тавтология — значение 1 при любых значениях.

## Условие

Буквы $x, y, z, u$ — элементарные высказывания; «$:$» — сильная дизъюнкция («одно и только одно из»). Какие формулы доказуемы в $S^2$? Критерий: формула доказуема тогда и только тогда, когда она тавтология и в посылке и заключении есть по крайней мере одно общее элементарное высказывание (гл. 3, § 2–3, MT1, MT4, с. 49–52).

а) $(\sim yy)x \vdash \sim z : \sim x\sim y$
б) $\sim(\sim x : x) \vdash (xy)(x : y)$
в) $(\sim y : y) : \sim y \vdash \sim(\sim zz)$
г) $\sim y : \sim x \vdash (x : z) : (\sim y : \sim x)$

## Ответ

а) да; б) да; в) нет; г) нет

## Решение

а) тавтология, и условие системы выполнено.
б) тавтология, и условие системы выполнено.
в) тавтология, но условие системы не выполнено: общих элементарных высказываний нет.
г) не тавтология: при $x = 0$, $y = 1$, $z = 1$ посылка — 1, заключение — 0.

Источник: с. 49, гл. 3, § 1.

## Условие

Буквы $x, y, z, u$ — элементарные высказывания; «$:$» — сильная дизъюнкция («одно и только одно из»). Студент проверил, что $zx \vdash \sim y : (y : \sim x)$ — тавтология, и решил, что в системе $S^2$ она недоказуема, проверив условие «в заключение не входят элементарные высказывания, отсутствующие в посылке». Студент применил условие системы $S^s$. В $S^2$ условие: в посылке и заключении есть по крайней мере одно общее элементарное высказывание; формула доказуема.

## Решение

Гл. 3, § 2, MT1, с. 49. Элементарные высказывания посылки: $x$, $z$; заключения: $x$, $y$.
