## Условие

Буквы $x, y, z, u, w$ — элементарные высказывания; запись по соглашению книги (с. 15). Подставьте в аксиомную схему A3 ($xy \vdash x$) вместо $x$ — $u$, $y$ — $x$ и запишите полученную аксиому.

## Ответ

$ux \vdash u$

## Решение

Схема A3 — с. 15. Подставляем и расставляем скобки по соглашению книги: составной член конъюнкции, если он дизъюнкция или конъюнкция, берётся в скобки; отрицание составного высказывания — $\sim(\dots)$.

## Условие

Буквы $x, y, z, u, w$ — элементарные высказывания; запись по соглашению книги (с. 15). Вычислите при главной интерпретации значения высказываний при $x = 0$, $y = 0$, $z = 0$.

а) $(x\sim x)\sim x(\sim xx) : x$
б) $(\sim xx)\sim z$
в) $(\sim x : x\sim xz : x) : x(y\sim y)(\sim zy)$
г) $y : \sim x$
д) $((\sim x : \sim z) : x\sim z : \sim y)((\sim yz)\sim x)$

## Ответ

а) 0; б) 0; в) 1; г) 1; д) 0

## Решение

Пункты 2–4 главной интерпретации (с. 22): $\sim$ меняет значение; конъюнкция имеет значение 1, когда все члены — 1; $x^1 : \ldots : x^n$ — когда одно и только одно из $x^i$ имеет значение 1. Значения вычисляются от элементарных высказываний к целому.

## Условие

Буквы $x, y, z, u, w$ — элементарные высказывания; запись по соглашению книги (с. 15). Для каждой формулы определите: сильная тавтология (§ 7, D1), тавтология, но не сильная, или не тавтология.

а) $(\sim x : x)(\sim yx) \vdash x$
б) $\sim x(\sim yx) \vdash (\sim y : \sim x) : (x : \sim y)$
в) $(y\sim x)x \vdash \sim y(x : z)x$
г) $y \vdash \sim x(yx)\sim y$

## Ответ

а) сильная тавтология; б) сильная тавтология; в) тавтология, но не сильная; г) не тавтология

## Решение

D1 § 7 (с. 25): сильная тавтология — тавтология (§ 5, D1), в заключение которой не входят элементарные высказывания, отсутствующие в посылке.
а) тавтология без новых элементарных высказываний.
б) тавтология без новых элементарных высказываний.
в) новые в заключении: $z$.
г) при $x = 0$, $y = 1$ формула имеет значение 0.

## Условие

Буквы $x, y, z, u, w$ — элементарные высказывания; запись по соглашению книги (с. 15). В выводе формулы $\sim \sim \sim(z : \sim(uw)) \vdash z\sim(uw) : \sim z\sim \sim(uw)$ ровно в одном шаге неверно указано основание. Найдите шаг и исправьте.

1. $\sim \sim \sim(z : \sim(uw)) \vdash \sim(z : \sim(uw))$ [A2]
2. $\sim(z : \sim(uw)) \vdash z\sim(uw) : \sim z\sim \sim(uw)$ [A4]
3. $\sim \sim \sim(z : \sim(uw)) \vdash z\sim(uw) : \sim z\sim \sim(uw)$ [R1: 1, 2]

## Ответ

Шаг 2: верно — A9.

## Решение

Проверяем каждый шаг по аксиомным схемам (с. 15–17) и правилам (с. 17). Верный вывод:

1. $\sim \sim \sim(z : \sim(uw)) \vdash \sim(z : \sim(uw))$ [A2]
2. $\sim(z : \sim(uw)) \vdash z\sim(uw) : \sim z\sim \sim(uw)$ [A9]
3. $\sim \sim \sim(z : \sim(uw)) \vdash z\sim(uw) : \sim z\sim \sim(uw)$ [R1: 1, 2]

## Условие

Буквы $a, b$ — элементарные высказывания. Найдите каноническую форму (§ 7, D2, D3) высказывания $\sim(\sim b : \sim a)$.

## Ответ

$ab : \sim a\sim b$ (порядок членов может быть любым)

## Решение

Значения (главная интерпретация, с. 22):

| $a$ | $b$ | значение |
|---|---|---|
| 1 | 1 | 1 |
| 1 | 0 | 0 |
| 0 | 1 | 0 |
| 0 | 0 | 1 |

Каждой строке со значением 1 соответствует член — конъюнкция $a$, $b$ с отрицаниями там, где значение 0. Полученное высказывание в канонической форме (D2), равнозначно исходному и содержит те же элементарные высказывания; поэтому обе формулы следования между ними — сильные тавтологии и по MT6 (с. 32) теоремы, что и требует D3 (с. 26).
