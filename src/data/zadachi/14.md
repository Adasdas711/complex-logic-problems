## Условие

Буква $a$ — название действия, $\tilde a$ — противоположное действие; $O$ — «обязательно», $P$ — «разрешено», $\text{З}$ — «запрещено», $\text{Б}$ — «безразлично», $\text{Н}$ — «необязательно». Каким аксиомным схемам $S^n_n$ (гл. 14, с. 189–190) соответствуют формулы?

а) $\urcorner O(a) \dashv\vdash P(\tilde a)$
б) $?P(a) \vdash \sim O(a)$
в) $\text{З}(a) \dashv\vdash \urcorner P(a)$

## Ответ

а) AII.2; б) AI.3; в) AIII.1

## Решение

Для каждой формулы ищем схему, из которой она получается заменой метапеременных (одинаковые буквы схемы — одинаковыми выражениями).

а) Схема AII.2: $\urcorner O(a) \dashv\vdash P(\tilde a)$. Формула получается из неё без замены букв.
б) Схема AI.3: $?P(a) \vdash \sim O(a)$. Формула получается из неё без замены букв.
в) Схема AIII.1: $\text{З}(a) \dashv\vdash \urcorner P(a)$. Формула получается из неё без замены букв.

Схемы — с. 189–190.

Действие $a$ — пользование библиотекой. Студент: «$a$ необязательно; значит, $a$ запрещено». Найдите ошибку.

## Ответ

Неверно: $\text{Н}(a)$ равнозначно $\urcorner O(a)$ и $P(\tilde a)$ (AV.1, AII.2): разрешено противоположное, а не запрещено $a$.

3. Запрет $a$ по AIII.1 — это $\text{З}(a) \dashv\vdash \urcorner P(a)$. Из $\text{Н}(a)$ он не следует: необязательное действие может быть и разрешено.
