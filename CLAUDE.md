# Правила работы с задачником

- Задачи строятся только по книге А. А. Зиновьева «Комплексная логика» (1970). «Очерки комплексной логики» (2000) не используются.
- Перед написанием задач к параграфу прочитать этот параграф в книге: формулы — по изображению страницы, а не по OCR (OCR искажает символы). Страница PDF = страница книги + 1.
- Классификация — `docs/02-klassifikaciya.md`, обозначения — `docs/04-oboznacheniya.md`, формат карточки — `docs/05-format-zadachi.md`.
- Квоты по параграфам и уровням — `docs/03-plan.md`; не превышать.
- Каждое решение ссылается на определения, аксиомы, правила и страницу книги. Утверждения, которых нет в книге и которые не выведены в решении, не допускаются.
- Сгенерированные файлы (`docs/01-…`, `docs/03-plan.md`, `docs/progress.md`, `docs/indeks-*.md`, `problems/*/README.md`, таблица разделов в `README.md`) руками не править: `python3 scripts/build.py`.
- Перед коммитом: `python3 scripts/validate.py` без ошибок и `python3 scripts/build.py --check`.
- Сканы и распознанный текст книги в репозиторий не добавлять.
