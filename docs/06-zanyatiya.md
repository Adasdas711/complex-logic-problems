# Занятия

Задачник разбит на **90 занятий** примерно по 40 задач — по образцу семинара Зиновьева: занятие 4–6 часов, 2 раза в неделю. Это **45 недель**.

В каждом занятии:

- **новый материал** — задачи очередных параграфов, по лестнице от простого к сложному;
- **повторение** — задачи из смешанного набора по уже пройденным главам: правила нужно узнавать вперемешку, а не по одному;
- около четверти задач в обеих частях — **диагностика**: найти, что не так, и назвать нарушенное правило.

Последние занятия целиком состоят из смешанных наборов — это итоговое повторение.

В повторении занятий 81–90 — **36 межглавных задач**: перенос между системами разных глав (кванторы и модальности, существование и модальности, условные высказывания и физическое следование, приложение и теория кванторов) и сравнение классических случаев разных глав.
