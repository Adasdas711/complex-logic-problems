### Глава 1. Сильное следование, § 4. Непарадоксальность

**Задача.** Буквы $x, y, z, u$ — элементарные высказывания; запись по соглашению книги (с. 15). Для каждой формулы выпишите элементарные высказывания, которые входят в заключение, но не входят в посылку.

а) $(z : \sim y) : \sim zz : \sim y \vdash (y\sim y)(\sim zuy)$
б) $\sim z\sim x : \sim x \vdash \sim u(\sim z\sim y)$
в) $y \vdash (u : x)(z : \sim z)$
г) $y : \sim yz : zx \vdash y(yz)$
д) $x\sim x : \sim y\sim xy : \sim y\sim xz \vdash \sim(y : x)$

**Решение.**

1. По MT1 § 4 (с. 21) в доказуемой в $S^1$ формуле в заключение не входят элементарные высказывания, отсутствующие в посылке. Поэтому для каждой формулы сравниваем два множества элементарных высказываний.
2. а) Посылка $(z : \sim y) : \sim zz : \sim y$ содержит $z$, $y$; заключение $(y\sim y)(\sim zuy)$ — $y$, $z$, $u$. Лишнее: $u$.
3. б) Посылка $\sim z\sim x : \sim x$ — $z$, $x$; заключение $\sim u(\sim z\sim y)$ — $u$, $z$, $y$. Лишние: $u$, $y$.
4. в) Посылка $y$; заключение $(u : x)(z : \sim z)$ — $u$, $x$, $z$. Лишние: $u$, $x$, $z$.
5. г) Посылка — $y$, $z$, $x$; заключение $y(yz)$ — $y$, $z$. Лишних нет.
6. д) Посылка — $x$, $y$, $z$; заключение $\sim(y : x)$ — $y$, $x$. Лишних нет.
7. Формулы а)–в) по MT1 недоказуемы в $S^1$; для г) и д) MT1 доказуемости не запрещает (но и не гарантирует её).

**Ответ.** а) $u$; б) $u$, $y$; в) $u$, $x$, $z$; г) нет; д) нет

### Глава 1. Сильное следование, § 5. Главная семантическая интерпретация

**Задача.** Буквы $x, y, z, u, w$ — элементарные высказывания; запись по соглашению книги (с. 15). Какие из формул следования — тавтологии при главной интерпретации (§ 5, D1)? Для остальных укажите значения элементарных высказываний, при которых формула имеет значение 0.

а) $\sim z(\sim x : y) \vdash \sim x$
б) $(\sim z\sim x)(\sim xx) \vdash (\sim z : y : \sim y)(x : \sim z)(\sim x : \sim z)$
в) $\sim(\sim yy) \vdash x : z$
г) $(\sim x : y) : (\sim y : z) \vdash \sim x : y : \sim y$

**Решение.**

а) при $x = 1$, $y = 1$, $z = 0$ посылка — 1, заключение — 0; формула имеет значение 0 (п. 5, с. 22).
б) ни при каких значениях посылка не имеет значения 1 при заключении 0 — тавтология (D1, с. 22).
в) при $x = 0$, $y = 0$, $z = 0$ посылка — 1, заключение — 0; формула имеет значение 0 (п. 5, с. 22).
г) при $x = 0$, $y = 0$, $z = 1$ посылка — 1, заключение — 0; формула имеет значение 0 (п. 5, с. 22).

**Ответ.** а) нет; б) да; в) нет; г) нет

## Решения

1\. С. 22: п. 1 — элементарные высказывания (значения 1 и 0); п. 2 — отрицание; п. 3 — конъюнкция; п. 4 — сильная дизъюнкция; п. 5 — формула следования.

2\. Перебираем 4 комбинации значений $x$, $y$ (с. 22). Тавтология — значение 1 при всех комбинациях; противоречие — высказывание, отрицание которого тавтология, то есть значение 0 при всех комбинациях.

3\. По § 4, MT1 (с. 21) формулы, где такие высказывания есть, недоказуемы в $S^1$.

4\. Пункты 2–4 главной интерпретации (с. 22): $\sim$ меняет значение; конъюнкция имеет значение 1, когда все члены — 1; $x^1 : \ldots : x^n$ — когда одно и только одно из $x^i$ имеет значение 1. Значения вычисляются от элементарных высказываний к целому.

26\. Ответ:

$x \supset y$ — высказывание $S^1$, сокращение для $xy : \sim xy : \sim x\sim y$; $x \vdash y$ — формула следования, высказывание о высказываниях. По MT5: если $x \vdash y$ — теорема $S^1$, то $x \supset y$ — тавтология; обратное неверно (например, $x \vdash y \supset x$).

Решение:

Введение, § 8 (с. 10); гл. 1, § 3, D1 (с. 20); § 5, MT5 (с. 24); MT3 § 4 (с. 21).

27\. $x \supset x$ — сокращение $xx : \sim xx : \sim x\sim x$ (§ 3, D1). При $x = 1$ истинен только первый член, при $x = 0$ — только третий: тавтология. Новых элементарных высказываний нет — сильная тавтология, по § 7, MT6 (с. 32) — теорема. Во второй формуле в заключение входит $y$ — по § 4, MT1 (с. 21) недоказуема (она названа в MT3).

28\. Ответ:

«Из противоречия — что угодно»: $\sim xx \vdash y$. «Истинное (всегда истинное) — из чего угодно»: $x \vdash y : \sim y$, $x \vdash \sim(\sim yy)$, $x \vdash y \vee \sim y$, а также $x \vdash y \supset x$, $x \vdash \sim x \supset y$.

Решение:

Примеры: «Идёт дождь и не идёт дождь; следовательно, Луна из сыра»; «Сегодня вторник; следовательно, либо снег белый, либо не белый». В $S^1$ такие формулы недоказуемы, потому что в заключении появляется $y$ (MT1, с. 21).
