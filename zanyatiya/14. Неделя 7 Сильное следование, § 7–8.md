## Примеры решений

**Пример 1.** Буквы $x, y, z, u, w$ — элементарные высказывания; запись по соглашению книги (с. 15). Таблица для A10 (§ 8, с. 33): значения 1 и 0, отмеченное значение 1; $x^1 : \ldots : x^n = x^1 \vee \ldots \vee x^n$; остальные операторы и $\vdash$ — как при главной интерпретации (§ 5). Какие из формул тавтологичны в этой таблице (принимают значение 1 при любых значениях элементарных высказываний)?

а) $x : y : z \vdash (x : y) : z$
б) $x \vdash \sim \sim x$
в) $(x : y)z \vdash xz : y$
г) $xy : \sim x\sim y \vdash \sim(x : y)$

**Решение.**

а) пример A11: тавтологична.
б) пример A1: тавтологична.
в) пример A14: тавтологична.
г) пример A10: при $x = 1$, $y = 1$ — значение 0.

Таблица построена так, что не тавтологичен только пример A10 (с. 33).

**Ответ.** а) да; б) да; в) да; г) нет

## Ответы и решения

### Решения

1\. Значения вычисляются от элементарных высказываний к целому, но по таблице, а не по главной интерпретации.

Источник: с. 33–35, гл. 1, § 8.

2\. Вычисление по таблице (с. 33–34). Так как остальные аксиомные схемы в этой таблице тавтологичны, а правила сохраняют тавтологичность, схема A4 не выводима из остальных.

3\. D5 (с. 26). $x^*$ — каноническая форма посылки: $ab : \sim ab$. $y^*$ — каноническая форма заключения: $b$. Высказываний вида $\sim aa$ в $x^*$ нет, поэтому $z$ пусто. $v$ — элементарные высказывания $x^*$, не входящие в $y^*$: $a$. $y^{**}$ — каноническая форма для $y^*(a : \sim a)$; это $ab : \sim ab$: члены — строки со значением 1 по $a$ и $b$.

4\. D5 (с. 26). $x^*$ — каноническая форма посылки: $\sim ab$. $y^*$ — каноническая форма заключения: $\sim a$. Высказываний вида $\sim aa$ в $x^*$ нет, поэтому $z$ пусто. $v$ — элементарные высказывания $x^*$, не входящие в $y^*$: $b$. $y^{**}$ — каноническая форма для $y^*(b : \sim b)$; это $\sim ab : \sim a\sim b$: члены — строки со значением 1 по $a$ и $b$.

5\. MT7 (с. 32); § 4, MT1 (с. 21).

6\. MT8 (с. 32): «если в $x$ и $y$ входят одинаковые элементарные высказывания». Формула $\sim\sim y \vdash \sim((x : y)x)$ к тому же недоказуема: в заключение входит $x$ (§ 4, MT1).

7\. MT8 (с. 32); § 4, MT1 (с. 21).

8\. Раскрываем сокращения: $\sim x(\sim xy) \vdash \sim(\sim \sim x\sim(\sim xy))$. Это сильная тавтология (§ 7, D1), по MT6 (с. 32) — теорема.

9\. Раскрываем сокращения: $(\sim x : x : y)((\sim x : x : y)(\sim xx) : \sim(\sim x : x : y)(\sim xx) : \sim(\sim x : x : y)\sim(\sim xx)) \vdash \sim xx$. Это сильная тавтология (§ 7, D1), по MT6 (с. 32) — теорема.

10\. Раскрываем сокращения: $(\sim y : y)((\sim y : y)y : \sim(\sim y : y)y : \sim(\sim y : y)\sim y) \vdash y$. Это сильная тавтология (§ 7, D1), по MT6 (с. 32) — теорема.

11\. Раскрываем сокращения: $y(yx : \sim yx : \sim y\sim x) \vdash x$. Это сильная тавтология (§ 7, D1), по MT6 (с. 32) — теорема.
