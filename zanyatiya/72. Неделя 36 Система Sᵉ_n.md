## Ответы и решения

### Решения

1\. 1. Схема (с. 162–163): $?E(a) \vdash \sim E(a \downarrow x)$; её буквы — метапеременные.
2. Одновременно заменяем каждое вхождение: $x$ → $(a \leftarrow c)(a \leftarrow d)$. Составное выражение, стоящее рядом с другим выражением или после оператора, берём в скобки, чтобы не изменилось строение формулы.
3. Получаем $?E(a) \vdash \sim E(a \downarrow (a \leftarrow c)(a \leftarrow d))$.

2\. 1. Схема AIV.1 (с. 162–166): $U(a) \vdash \urcorner E(\sim a)$.
2. Посылка формулы подходит под схему при $a$ — $b$. Тогда по схеме заключение должно быть $\urcorner E(\sim b)$, а у студента — $\sim E(\sim b)$.
3. Формула студента получается из схемы AIV*.1: $U(a) \vdash \sim E(\sim a)$ при $a$ — $b$.
4. Значит, формула — не пример схемы AIV.1.

3\. 1. Схема (с. 162–163): $E(a)\sim E(a \downarrow b) \vdash E(a\sim \downarrow b)$; её буквы — метапеременные.
2. Одновременно заменяем каждое вхождение: $b$ → $d$; $a$ → $cd$. Составное выражение, стоящее рядом с другим выражением или после оператора, берём в скобки, чтобы не изменилось строение формулы.
3. Получаем $E(cd)\sim E(cd \downarrow d) \vdash E(cd\sim \downarrow d)$.

4\. а) шаг 1: $(a \leftarrow b)(a \leftarrow c) \vdash (a \leftarrow b)(a \leftarrow c)$ доказуема в $S^s$; шаг 2: по п. 1 D1 контрольная форма совпадает с формулой; она не тавтология (с. 109).  
б) шаг 1: $(a \leftarrow b)(a \leftarrow c) \vdash (a \leftarrow b)(a \leftarrow c)$ доказуема в $S^s$; шаг 2: по п. 1 D1 контрольная форма совпадает с формулой; она тавтология (с. 109).  
в) шаг 1: $(a \leftarrow b) \vee (a \leftarrow c) \vdash (a \leftarrow b) \vee (a \leftarrow c)$ доказуема в $S^s$; шаг 2: по п. 1 D1 контрольная форма совпадает с формулой; она не тавтология (с. 109).

18\. 1. Схема (с. 162–163): $x \vdash E(\downarrow x)$; её буквы — метапеременные.
2. Одновременно заменяем каждое вхождение: $x$ → $\sim(a \leftarrow c)$. Составное выражение, стоящее рядом с другим выражением или после оператора, берём в скобки, чтобы не изменилось строение формулы.
