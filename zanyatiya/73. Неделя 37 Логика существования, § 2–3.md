## Примеры решений

**Пример 1.** Буквы $a, b, c$ — термины; $x, y$ — высказывания; $E$ — «существует», $U$ — «универсально». Термины $a, b, c$ здесь простые. Доказуема ли в $S^e_n$ формула $\vdash U(t)$ для каждого термина $t$ (MT1 § 4 гл. 11, с. 164–165)?

а) $t = \sim c \vee b \vee c$  
б) $t = c \vee a \vee \sim c$  
в) $t = \sim (b \vee a)$

<details>
<summary>Решение</summary>

**Решение.**

а) $t^* = \sim c \vee b \vee c$ (буквы — высказывания) — тавтология; доказуема.  
б) $t^* = c \vee a \vee \sim c$ (буквы — высказывания) — тавтология; доказуема.  
в) $t^* = \sim (b \vee a)$ (буквы — высказывания) — не тавтология; недоказуема.

MT1, п. 2: $\vdash U(a)$ доказуема тогда и только тогда, когда тавтологией является $a^*$, полученное заменой терминов высказываниями (разные — разными, одинаковые — одинаковыми).

**Ответ.** а) да; б) да; в) нет

</details>

2. Посылка формулы подходит под схему без замены букв. Тогда по схеме заключение должно быть $(U(a \vee \sim a))$, а у студента — $E(b \vee \sim b)$.

3. AVIII.1 $x \vdash E(\downarrow x)$ (с. 163): в заключение входит предикат $E$. Это простой предикат, то есть термин (D3 § 1 гл. 9, с. 138). В посылке $x$ его может не быть — условие нарушено.

45\. а) $t^* = a \vee c \vee \sim c$ (буквы — высказывания) — тавтология; доказуема.  
б) $t^* = \sim c \vee a \vee c$ (буквы — высказывания) — тавтология; доказуема.  
в) $t^* = (bc)a$ (буквы — высказывания) — не тавтология; недоказуема.

MT1, п. 2: $\vdash U(a)$ доказуема тогда и только тогда, когда тавтологией является $a^*$, полученное заменой терминов высказываниями (разные — разными, одинаковые — одинаковыми).

46\. Эскиз.
1. П. 5 интерпретации (с. 166): при $a = b = 1$ значение $ab$ неопределённо; при $ab = 0$ значения $a$, $b$ неопределённы.
2. Схемы с $ab$: AVII.1, AVII.3, AVII.5, AV.1–2. Проверить каждую: какая часть п. 5 используется (AVII.1 — «если $ab = 1$, то $a = b = 1$»; AVII.3 — «если хотя бы один 0, то $ab = 0$»).
3. Изменение: «если $a = b = 1$, то $ab = 1$». Тогда $E(a)E(b) \vdash E(ab)$ стала бы тавтологией, и MT2 перестала бы выполняться.
4. Почему книга его не принимает: термином $ab$ обозначается лишь то, что может быть названо и $a$, и $b$ одновременно (с. 138). Из существования $a$ и существования $b$ не следует существование предмета, который есть и $a$, и $b$.
