## Примеры решений

**Пример 1.** Ряд $A$ — эмпирический, ряд $B$ — абстрактный (отрезок прямой из точек); число элементов каждого бесконечно. Что следует по § 30 о протяжённости $A$ и о протяжённости $B$?

<details>
<summary>Решение</summary>

**Решение.**

1. По с. 95 конечность ряда понимается по-разному: по началу и концу, по числу элементов, по протяжённости.
2. Для эмпирического ряда: бесконечное число элементов влечёт бесконечную протяжённость (с. 95) — $A$ бесконечно протяжён.
3. Для абстрактного ряда это правило не действует (с. 95): $B$ может иметь конечную протяжённость.

**Ответ.** $A$ бесконечно протяжён; о $B$ из бесконечности числа точек ничего подобного не следует — отрезок конечной длины содержит бесконечно много точек (с. 95).

</details>

**Пример 2.** Буквы $a, b, c, d, e, f$ — индивиды; $\alpha^1, \alpha^2$ — способы установления порядка. По с. 97 элементы скопления $A$ образуют структуру относительно класса способов $B$, если и только если для любого элемента $u$ скопления найдётся другой элемент $v$ и способ $\alpha$ из $B$, что $u > \alpha v$ или $v > \alpha u$. Для каждого способа принимается аналог аксиомы C4 (с. 82): $(u > \alpha v) \wedge (v > \alpha w) \vdash (u > \alpha w)$. Известно: $a > \alpha^1 b$; $e > \alpha^1 f$; $f > \alpha^1 a$; $d > \alpha^2 b$; $e > \alpha^2 d$; других отношений по $\alpha^1$ и $\alpha^2$ между этими индивидами нет, кроме выводимых из данных по аналогу C4. Для каждого скопления и класса способов $B$ установите, образуют ли его элементы структуру относительно $B$, и обоснуйте.

а) скопление $a, b, d, f$, $B = \{\alpha^2\}$  
б) скопление $a, e$, $B = \{\alpha^1\}$  
в) скопление $a, b, d$, $B = \{\alpha^1\}$  
г) скопление $b, d, e, f$, $B = \{\alpha^1, \alpha^2\}$

<details>
<summary>Решение</summary>

**Решение.**

а) для $a$ нет ни другого элемента скопления, ни способа из $B$; для $b$ — $d > \alpha^2 b$; для $d$ — $d > \alpha^2 b$; для $f$ нет ни другого элемента скопления, ни способа из $B$ — не образуют (с. 97).  
б) для $a$ — $e > \alpha^1 a$ (из $e > \alpha^1 f$ и $f > \alpha^1 a$ по аналогу C4, с. 82); для $e$ — $e > \alpha^1 a$ (из $e > \alpha^1 f$ и $f > \alpha^1 a$ по аналогу C4, с. 82) — образуют (с. 97).  
в) для $a$ — $a > \alpha^1 b$; для $b$ — $a > \alpha^1 b$; для $d$ нет ни другого элемента скопления, ни способа из $B$ — не образуют (с. 97).  
г) для $b$ — $d > \alpha^2 b$; для $d$ — $d > \alpha^2 b$; для $e$ — $e > \alpha^1 f$; для $f$ — $e > \alpha^1 f$ — образуют (с. 97).

**Ответ.** а) не образуют; б) образуют; в) не образуют; г) образуют.

</details>

## Ответы и решения

### Решения

1\. С. 95: «ряды бывают конечные и бесконечные в смысле наличия или отсутствия начального или конечного элемента. Но они также различаются как конечные и бесконечные с точки зрения числа входящих в них элементов и с точки зрения протяженности».

2\. С. 95: «Если число элементов эмпирического ряда бесконечно, то ряд бесконечно протяжен». Это связано с тем, что протяжённость эмпирических индивидов не бывает нулевой или бесконечно малой (с. 92).

3\. С. 95: «Если число элементов эмпирического ряда бесконечно, то ряд бесконечно протяжен. Для абстрактного ряда это не так. Например, отрезок $AB$ на рис. 4 содержит бесконечное множество точек, но имеет конечную протяженность».

4\. 1. С. 95: «Для абстрактных рядов правомерны любые допущения, лишь бы они были логически непротиворечивы… Можно даже допустить ряд, который бесконечно протяжен, но имеет начальный и конечный элемент (если, например, допустить бесконечно большой интервал между его элементами)».
2. С. 95–96: для эмпирических рядов такие допущения либо остаются неверифицируемыми гипотезами, либо такие абстрактные ряды не имеют эмпирических интерпретаций: «абстрактный ряд с бесконечно протяженными интервалами между какими-либо его элементами не имеет эмпирической интерпретации».

5\. Элементы $A$ образуют структуру относительно $B$, если и только если для любого элемента $a$ найдётся другой элемент $b$ и способ $\alpha$ из $B$, что $a > \alpha b$ или $b > \alpha a$ (с. 97). Проверка: для $a$: $b > \alpha^1 a$; для $b$: $b > \alpha^1 a$; для $c$: $b > \alpha^1 c$; для $d$: $b > \alpha^1 d$. Условие выполнено.

6\. Элементы $A$ образуют структуру относительно $B$, если и только если для любого элемента $a$ найдётся другой элемент $b$ и способ $\alpha$ из $B$, что $a > \alpha b$ или $b > \alpha a$ (с. 97). Проверка: для $a$ нет другого элемента, отличного от него по порядку ни относительно одного способа из $B$; для $b$ нет другого элемента, отличного от него по порядку ни относительно одного способа из $B$; для $c$ нет другого элемента, отличного от него по порядку ни относительно одного способа из $B$; для $d$ нет другого элемента, отличного от него по порядку ни относительно одного способа из $B$. Условие нарушено.

41\. С. 97, первый абзац. В имплицитном определении слово «структура» определено как часть высказывания; чтобы ввести термин «структура» как самостоятельный, нужны дополнительные логические операции.

42\. 1. Ряд кирпичей непрерывен по с. 87: соседние элементы попарно соприкасаются.
2. Определение с. 93 требует: для любых $a$, $b$ найдётся элемент $c$ между ними.
3. Для двух соседних кирпичей такого элемента нет (они соседние, с. 85). Значит, определение § 29 не выполнено: «несовпадение этих определений с соответствующими определениями для эмпирических рядов очевидно» (с. 93).

Ответ:

Утверждение неверно: по § 29 между любыми двумя элементами должен быть третий; между соседними кирпичами нет кирпича. Эмпирический ряд непрерывен в смысле соприкосновения соседних (с. 87), абстрактный — в смысле «между любыми двумя есть третий» (с. 93).

43\. С. 99: определения подструктуры, собственной подструктуры и отношения «находится внутри». Пример — рис. 7: скопление $a, b, c$ есть подструктура скопления $a, b, c, d$.

44\. Порядок по данным и C4 (от уступающих к превосходящим): $c, e, d, b, f, a$.  
а) между ними элемент $d$ — индивид класса; поместить индивид можно — не соприкасаются.  
б) между ними элемент $e$ — индивид класса; поместить индивид можно — не соприкасаются.  
в) соседние, но между ними можно поместить индивид — не соприкасаются.  
г) между ними элемент $d$ — индивид класса; поместить индивид можно — не соприкасаются.  
д) между ними элемент $f$ — индивид класса; поместить индивид можно — не соприкасаются.

Источник: с. 82, 87, гл. 2, § 24.

45\. С. 87: эмпирический ряд непрерывен, е. т. е. $(\forall a)(\forall b)((a \in A) \wedge (b \in A) \wedge (a \mid \alpha b) \to (a \parallel \alpha b))$. С. 93: абстрактный — $(\forall a)(\forall b)(\exists c)(…)$, $c$ между $a$ и $b$. С. 93: различие «имеет первостепенное значение для устранения… парадоксов Зенона», которые «совершенно непреодолимы», если его не учитывать; с. 93–94: ошибка интерпретации — «будто для любых двух элементов эмпирического ряда имеется такой элемент, который помещается между ними. И так без конца».

Ответ:

Эмпирический: каждая пара соседних элементов соприкасается. Абстрактный: для любых двух элементов есть третий между ними. Смешение (переносить «между любыми двумя есть третий» на эмпирический ряд) порождает бесконечное деление и затруднения, непреодолимые без различения рядов.

46\. С. 98: «Простейшая структура — структура из двух индивидов и одного способа установления порядка». Определение с. 97 требует для любого элемента $a$ другого элемента $b$; в скоплении из одного индивида его нет. Частный случай скопления в определении — $a^1, …, a^n$ при $n \geqslant 2$ (с. 97).
