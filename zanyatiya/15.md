# Ответы и решения

## Ответы

| № | Ответ |
|---|---|
| 1 | Неверно: обе части равны 1, и формула имеет значение 1 при любых значениях. |
| 2 | $\sim(y : z) \vdash \sim(y : z)\sim(y : z)$ |
| 3 | строка 1: заключение 0, формула 0; строка 2: заключение 0, формула 1; формула не тавтологична. |
| 4 | строка 2: заключение 0, формула 0; строка 3: заключение 1, формула 1; формула не тавтологична. |
| 5 | строка 2: заключение 0, формула 0; строка 4: заключение 0, формула 1; формула не тавтологична. |
| 6 | $\sim\sim x$ — это $\sim$ от $\sim x$, а по таблице $\sim$ от чего угодно равно 0: $\sim\sim x = 0$. При $x = 1$ формула имеет значение 0. |
| 7 | В этой таблице $\sim x = x$: $\sim(x : y) = x : y = 1$. Заключение: $xy = 0$, $\sim x\sim y = xy = 0$, $0 : 0 = 0$. Формула имеет значение 0. |
| 8 | $\sim z : y$ вместо $x$; доказуема. |
| 9 | MT1 § 9 требует подстановки везде, где элементарное высказывание входит в формулу; $xy \vdash z$ недоказуема. |
| 10 | Например, при $x = 0$, $y = 0$, $z = 1$: посылка — 0, заключение — 1, формула — 2. |
| 11 | Например, при $x = 0$, $y = 1$: посылка — 0, заключение — 2, формула — 2. |
| 12 | В этой таблице отмеченное значение — 0, а не 1: значение 0 у формулы следования как раз «хорошее». A6 здесь тавтологична. |
| 13 | MT1 § 9 разрешает подставлять высказывание вместо элементарного, а не элементарное вместо составного. $wx \vdash \sim y$ недоказуема. |
| 14 | а) да; б) да; в) да; г) нет |
| 15 | а) да; б) нет; в) да; г) да |
| 16 | а) нет; б) да; в) да; г) да |

| 19 | получается; доказуема |
| 20 | получается; доказуема |

25\. Ответ:

R1: если $x = 1$ влечёт $y = 1$, а $y = 1$ — $z = 1$, то $x = 1$ влечёт $z = 1$. R3: из тавтологичности $x \vdash y$ и $y \vdash x$ — равнозначность, замена не меняет значений. R2: $a \vdash a$ тавтологична, а $a \vdash aa$ — нет.

Решение:

При $a = 1$: $aa = 0$, формула 0. Значение $\vdash$ обычное (п. 5 § 5), значения составных высказываний определяются значениями частей.

26\. Ответ:

Всякое составное высказывание имеет значение 0, поэтому формула со составным заключением всегда 1. R2 даёт заключение-конъюнкцию — всегда 1. R3: если $v$ составное — всегда 1; если $v$ элементарное, то $v$ — это $y$, заменившее всё $z$ ($z$ — это $x$), и $z \vdash v$ совпадает с посылкой $x \vdash y$.

Решение:

R2, R3 — с. 17.
