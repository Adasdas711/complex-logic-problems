## Ответы и решения

### Решения

1\. Элементы $a$ и $b$ ряда соседние, если и только если ни один элемент $A$ не находится между ними относительно $\alpha$ (с. 85); «между» — по § 20 (с. 82).

а) между $a^4$ и $a^5$ нет элемента $A$ — соседние (то, что между ними можно поместить индивид, на соседство не влияет).  
б) $a^2$ — элемент $A$ и находится между ними: $(a^2 > \alpha a^1) \wedge (a^4 > \alpha a^2)$ — не соседние.  
в) между $a^3$ и $a^4$ нет элемента $A$ — соседние (то, что между ними можно поместить индивид, на соседство не влияет).  
г) $a^2$ — элемент $A$ и находится между ними: $(a^2 > \alpha a^1) \wedge (a^3 > \alpha a^2)$ — не соседние.

2\. Определение 1–2 (с. 87): $a \parallel \alpha b$, если $(a > \alpha b) \vee (b > \alpha a)$ и $(\urcorner\mathrm{M} I)$ поместить $I$ между $a$ и $b$.

а) $a^2 > \alpha a^1$; между ними можно поместить индивид — $a^1 \urcorner \parallel \alpha a^2$.  
б) $a^8 > \alpha a^7$; поместить индивид между ними нельзя — $a^7 \parallel \alpha a^8$.

г) между $a^6$ и $a^8$ находится элемент $a^7$ — индивид класса; $a^6 \urcorner \parallel \alpha a^8$.

3\. 1. Оба скопления образуют структуру: любые два элемента упорядочены относительно $\alpha$ (с. 97).
2. $A^1 \subset A^2$: каждый элемент $A^1$ входит в $A^2$ — $C$ есть подструктура $D$ относительно $B$ (с. 99).

Источник: с. 82, 87, гл. 2, § 24.

30\. а) для $d$ — $d > \alpha^1 e$; для $e$ — $d > \alpha^1 e$; для $f$ — $f > \alpha^2 e$ — образуют.  
б) для $a$ — $d > \alpha^1 a$ (из $d > \alpha^1 e$ и $e > \alpha^1 a$ по аналогу C4, с. 82); для $d$ — $d > \alpha^1 a$ (из $d > \alpha^1 e$ и $e > \alpha^1 a$ по аналогу C4, с. 82); для $f$ партнёра нет — не образуют.  
в) для $a$ — $f > \alpha^2 a$ (из $f > \alpha^2 e$ и $e > \alpha^2 a$ по аналогу C4, с. 82); для $f$ — $f > \alpha^2 a$ (из $f > \alpha^2 e$ и $e > \alpha^2 a$ по аналогу C4, с. 82) — образуют.  
г) для $a$ — $d > \alpha^2 a$; для $d$ — $d > \alpha^2 a$; для $e$ — $e > \alpha^2 d$; для $f$ — $f > \alpha^2 e$ — образуют.  
д) для $d$ партнёра нет; для $f$ партнёра нет — не образуют.

Определение — с. 97: партнёр нужен каждому элементу, и способ должен принадлежать $B$.
