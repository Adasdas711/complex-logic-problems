## Условие

Буквы $a, b, c, d$ — термины. Укажите номера теоремных схем $S^1_t$ (с. 140):

а) $\vdash (a \rightharpoonup b)(a \rightharpoonup c) \to (a \rightharpoonup (b \vee c))$
б) $\vdash (a \vee b) \rightharpoonup a$
в) $\vdash (a \vee b) \rightharpoonup (b \vee a)$

## Ответ

а) T5; б) T1; в) T7

## Решение

Для каждой формулы ищем схему, из которой она получается заменой метапеременных (одинаковые буквы схемы — одинаковыми выражениями).

а) Схема T5: $\vdash (a \rightharpoonup b)(a \rightharpoonup c) \to (a \rightharpoonup (b \vee c))$. Формула получается из неё без замены букв.
б) Схема T1: $\vdash (a \vee b) \rightharpoonup a$. Формула получается из неё без замены букв.
в) Схема T7: $\vdash (a \vee b) \rightharpoonup (b \vee a)$. Формула получается из неё без замены букв.

Схемы — с. 140.

в) Схема T1: $\vdash (a \leftarrow (bc)) \to (a \leftarrow b)(a \leftarrow c)$. Формула получается из неё без замены букв.

## Условие

Буквы $a, b, c$ — термины. Укажите номера следствий $S^2_t$ (с. 142–143):

а) $\vdash \sim(a \leftarrow b) \to \sim(a \leftarrow bc)$
б) $\vdash \sim((a \leftarrow b)(a \leftarrow \tilde b))$
в) $\vdash \sim(a \leftarrow (b \vee c)) \to \sim(a \leftarrow b)$

## Ответ

а) T5; б) T11; в) T6

## Решение

б) Схема T11: $\vdash \sim((a \leftarrow b)(a \leftarrow \tilde b))$. Формула получается из неё без замены букв.
в) Схема T6: $\vdash \sim(a \leftarrow (b \vee c)) \to \sim(a \leftarrow b)$. Формула получается из неё без замены букв.

## Условие

Восстановите рассуждение с. 143–144: почему нельзя принимать $\vdash (a \leftarrow b)(a \leftarrow c) \to (a \leftarrow (bc))$?

## Ответ

Тогда пришлось бы принять $\vdash (a \leftarrow b)(a \leftarrow \sim b) \to (a \leftarrow (\sim bb))$, а по AII.1 и $S^5$ — $\vdash \sim((a \leftarrow b)(a \leftarrow \sim b))$, что не соответствует смыслу $\sim b$: предмет может иметь признак $b$ и другой признак, не обозначаемый $b$.
