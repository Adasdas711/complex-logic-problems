## Условие

Буквы $x, y, z, u, w$ — элементарные высказывания; запись по соглашению книги (с. 15). Вычислите при главной интерпретации значения высказываний при $x = 1$, $y = 0$, $z = 1$.

а) $\sim(z\sim z : (\sim y : x : z))$
б) $\sim x : (x\sim y : \sim x)$
в) $(yx : \sim y)((\sim x : z)\sim x)$
г) $(y : (x : \sim z)) : \sim x$
д) $\sim(\sim x : \sim y) : y$

## Ответ

а) 1; б) 1; в) 0; г) 1; д) 0

## Решение

Пункты 2–4 главной интерпретации (с. 22): $\sim$ меняет значение; конъюнкция имеет значение 1, когда все члены — 1; $x^1 : \ldots : x^n$ — когда одно и только одно из $x^i$ имеет значение 1. Значения вычисляются от элементарных высказываний к целому.

## Условие

Буквы $x, y, z, u, w$ — элементарные высказывания; запись по соглашению книги (с. 15). Для каждой формулы определите: сильная тавтология (§ 7, D1), тавтология, но не сильная, или не тавтология.

а) $(\sim xx\sim y)(\sim x : \sim y) \vdash \sim y$
б) $\sim y \vdash (\sim y : z)\sim x$
в) $\sim(\sim x : x) \vdash \sim y\sim x$
г) $(x\sim x)(\sim x\sim y) \vdash \sim y$

## Ответ

а) сильная тавтология; б) не тавтология; в) тавтология, но не сильная; г) сильная тавтология

## Решение

D1 § 7 (с. 25): сильная тавтология — тавтология (§ 5, D1), в заключение которой не входят элементарные высказывания, отсутствующие в посылке.
а) тавтология без новых элементарных высказываний.
б) при $x = 0$, $y = 0$, $z = 1$ формула имеет значение 0.
в) новые в заключении: $y$.
г) тавтология без новых элементарных высказываний.

## Условие

Буквы $a, b, c, d$ — термины (субъекты и одноместные предикаты); $x, y$ — высказывания. Дано высказывание $(\forall a)(d \leftarrow a)$. Для каждого термина укажите: свободен ли он в высказывании по D4 и есть ли у него свободные вхождения по D5 (§ 1 гл. 7, с. 98–99).

## Ответ

$a$ — не свободен, свободных вхождений нет; $d$ — свободен, есть свободные вхождения

## Решение

D4: термин свободен, если входит в высказывание, а кванторные группы с ним не входят. D5: вхождение связано, если стоит в области действия кванторной группы с этим термином; иначе свободно.

## Условие

Буквы $x, y, z, u, w$ — элементарные высказывания; запись по соглашению книги (с. 15). Студент проверил формулу $x(\sim x : y) \vdash \sim(\sim y : x)$: «при $x = 1$, $y = 1$ посылка имеет значение 1, заключение — 0, значит, формула имеет значение 1; так при всех значениях — тавтология». Найдите ошибку.

## Ответ

При этих значениях формула имеет значение 0 (посылка 1, заключение 0), поэтому она не тавтология.

## Решение

Главная интерпретация, п. 5 (с. 22): $x \vdash y$ имеет значение 0 тогда и только тогда, когда $x$ имеет значение 1, а $y$ — 0. D1 (с. 22): тавтология — значение 1 при любых значениях.

## Условие

Буквы $a, b, c, d$ — термины; $x, y, z, v$ — высказывания. Постройте интерпретационную форму высказывания $(\exists a)\sim (a \leftarrow b)$ (D2 § 7 гл. 7, с. 105) при $3$ отмеченных терминах для $a$: $1a, \ldots, 3a$ (термины $b$, $c$ здесь не связаны кванторами; отмечать их не нужно).

## Ответ

$\sim (1a \leftarrow b) \vee \sim (2a \leftarrow b) \vee \sim (3a \leftarrow b)$

## Решение

D2, п. 3 (с. 105): $(\forall a)z$ заменяется конъюнкцией $z(1a) \cdot \ldots \cdot z(na)$, $(\exists a)z$ — дизъюнкцией $z(1a) \vee \ldots \vee z(na)$; вложенные кванторы — изнутри наружу.

## Условие

Буквы $a, b$ — элементарные высказывания. Студент нашёл каноническую форму $\sim(\sim a : (a : b) : a)$: $a\sim b : \sim ab : ab$. Найдите ошибку.

## Ответ

Ошибка: лишний член $ab$: при соответствующих значениях исходное высказывание имеет значение 0. Верно: $a\sim b : \sim ab$.

## Решение

D2, D3 (с. 25–26): каноническая форма должна быть в канонической форме и равнозначна исходному высказыванию (обе формулы следования — теоремы, а значит, тавтологии по § 5, MT1).

## Условие

Буквы $a, b, c, d$ — термины (субъекты и одноместные предикаты); $x, y$ — высказывания. Запишите бескванторную форму (D7 § 1 гл. 7) формулы $(a \leftarrow c) \vee \sim (d \leftarrow a) \vdash (\exists a)(a \leftarrow d) \vee \sim (c \leftarrow d)$.

## Ответ

$(a \leftarrow c) \vee \sim (d \leftarrow a) \vdash (a \leftarrow d) \vee \sim (c \leftarrow d)$

## Решение

D7 (с. 99): исключаются все кванторные группы.

## Условие

Буквы $a, b, c, d$ — термины; $x, y, z, v$ — высказывания. Постройте интерпретационную форму формулы $(\forall a)\sim (a \leftarrow b) \vdash (\forall a)(a \leftarrow b)$ при 1 отмеченном термине для каждого связанного термина и установите, тавтология ли она.

## Ответ

$\sim (1a \leftarrow b) \vdash (1a \leftarrow b)$; не тавтология

## Решение

D2 § 7 (с. 105). Контрпример: $(1a \leftarrow b) = 0$. По D3 формула — тавтология, если такова каждая её интерпретационная форма при любом числе отмеченных терминов.
