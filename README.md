# Задачник по комплексной логике

3600 задач по книге **А. А. Зиновьева «Комплексная логика»** (М.: Наука, 1970) и раздел о координатах высказываний по его более поздним работам.

Задачник рассчитан на выработку навыка, а не на знакомство с книгой: около 30 решений на каждый элементарный навык, четверть задач — диагностика ошибок («что здесь не так и какое правило нарушено»), разбивка на 90 занятий по образцу семинара Зиновьева.

## Как устроен репозиторий

```
zanyatiya/                  документы занятий, контрольных и входных тестов (генерируются)
src/                        задачник
  books/                    PDF книг: «Комплексная логика» (1970), «Логическая физика» (1972),
                            «Очерки комплексной логики» (2000), «Logische Sprachregeln» (Зиновьев, Вессель)
  data/zadachi/<ГГ>.md      задачи: один служебный файл на главу (документы занятий собираются из них)
  data/primery/             разобранные примеры: по одному на параграф
  data/povtorenie/          плановое повторение: каждый параграф через неделю и через месяц
  data/kontrolnye/KNN.md    контрольные работы (не повторяют задачи занятий)
  data/vhodnye/VNN.md       входные тесты к главам: 8–10 задач на то, что глава берёт из прежних
  data/toc.yaml, taxonomy.yaml, metki.yaml   содержание книги; классификация; метки, сверенные по страницам
  docs/                     документация и сгенерированные указатели
  templates/zadacha.md      шаблон карточки
  scripts/build.py          сборка оглавлений, плана, занятий, указателей
  scripts/site.py           данные сайта (site_src/data/) и сборка _site/ для публикации
  scripts/validate.py       проверка карточек; lint.py — содержания (-k контрольные, -t входные тесты)
  scripts/check_subst.py    пересчёт подстановок в схемы
  scripts/check_answers.py  пересчёт других ответов: выводы, тавтологичность, доказуемость, схемы, значения
  scripts/check_refs.py     метка из решения (A5, D2, MT3…) стоит на указанной странице книги
  scripts/expand_solutions.py, split_cards.py, pdf.py   пошаговые решения; черновики → карточки; печатная версия
  scripts/logic/            модели языка и систем книги
  scripts/gen/              генераторы серий, контрольных, повторения, входных тестов
index.html                  сайт: открывает site_src/ (меню, занятия, поиск)
site_src/                   код и оформление сайта; data/ — данные занятий (генерируются; см. site_src/README.md)
.github/workflows/sborka.yml  проверки, пересборка занятий, публикация сайта
```

Изменили задачи и запушили в main — GitHub Actions проверит карточки, пересоберёт занятия и данные сайта
(и сам закоммитит изменения); когда репозиторий станет публичным, опубликует сайт на GitHub Pages.
Посмотреть сайт у себя: `python3 -m http.server` в корне репозитория → http://localhost:8000.

После добавления задач:

```bash
pip install -r requirements.txt
python3 src/scripts/validate.py
python3 src/scripts/build.py
python3 src/scripts/site.py
```
