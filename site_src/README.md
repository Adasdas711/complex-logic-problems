# Сайт задачника

Сайт — это `index.html` в корне репозитория и эта папка. Сборка не нужна: страница сама загружает
данные из `site_src/data/`. Дизайн (ПК): https://claude.ai/artifact/Tj2GvbBQRPJPg9VDUYsdZU

```
index.html             (в корне) страница сайта
site_src/
├─ app.css             тёмная тема как в макете
├─ app.js              меню, поиск, экраны, отметки «выполнено»
└─ data/               данные занятий — генерируются, руками не править
```

Посмотреть у себя: `python3 -m http.server` в корне репозитория → http://localhost:8000
(как файл, двойным щелчком, страница данные не загрузит).

## Как обновляется

Изменили задачи в `src/data` и запушили в main → GitHub Actions (`.github/workflows/sborka.yml`):
1. проверяет карточки и пересчитывает ответы программой;
2. пересобирает документы `zanyatiya/` (`src/scripts/build.py`) и данные сайта `site_src/data/` (`src/scripts/site.py`)
   и сам их коммитит;
3. когда репозиторий публичный, публикует на GitHub Pages: `index.html` + `site_src/` (собираются в `_site/`).

Сайт и документы берут задачи из одной раскладки (`build.session_models`), поэтому всегда совпадают.

Публикация: Settings → Pages → Build and deployment → Source: **GitHub Actions**.
Вариант «Deploy from a branch → main, / (root)» тоже работает (в корне есть `index.html` и `.nojekyll`),
но коммит робота с пересобранными данными GitHub Pages не пересобирает — новые данные появятся
на сайте только со следующим вашим пушем. Поэтому лучше GitHub Actions.

## Данные (собирает `src/scripts/site.py`)

| Файл | Что внутри |
|---|---|
| `data/index.json` | модули (название, цель, главы); занятия: номер, неделя, тема, модуль, главы, число задач; контрольные; входные тесты — для меню, сетки занятий и поиска |
| `data/z/NN.json` | занятие NN: что прочитать (страницы книги и PDF), повторение, примеры решений, задачи в порядке занятия: `n`, `id`, `level`, `type`, `cond`, `ans`, `sol` |
| `data/k/NN.json` | контрольная работа NN: критерий сдачи, время, задачи и для каждой — какой параграф повторить и в каких занятиях он шёл |
| `data/t/NN.json` | входной тест к главе NN — то же |
| `data/spravka.json` | обозначения, ступени, типы задач |

Условия, ответы и решения уже переведены в HTML (`src/scripts/html_fmt.py`): формулы набраны
символами книги шрифтом STIX Two Text, индексы — верхние и нижние (S<sup>e</sup><sub>n</sub> — стопкой).

## Поведение

- Поиск — по номеру занятия (префикс: «7» → 7, 70–79) и по словам из темы; «Sen» и «S^e_n» находят Sᵉ_n.
- Ответы и решения свёрнуты; переключатель «В конце / Под задачей».
- Отметки «задача решена», «занятие выполнено», «работа выполнена», «тест выполнен» — только в `localStorage`
  этого браузера: зелёные плитки, ✓ и полоски «выполнено N из M» у модулей в меню. Прогресс никуда не отправляется.
