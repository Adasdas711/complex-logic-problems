# Сайт задачника

Исходники сайта-сборника занятий. Готовый сайт собирает `python3 src/scripts/site.py` в `_site/`
(в репозиторий не кладётся); после пуша в main это делает GitHub Actions (`.github/workflows/sborka.yml`)
и публикует сайт на GitHub Pages, когда репозиторий публичный.

Дизайн всех страниц (ПК): https://claude.ai/artifact/Tj2GvbBQRPJPg9VDUYsdZU

## Что сюда положить

```
site_src/
├─ index.html          одна страница: меню, поиск, экраны «Курс», «Занятие», «Модуль», «Контрольные»,
│                      «Входные тесты», «Поиск», «Обозначения», «Как устроены задачи»
├─ app.css             тёмная тема как в макете
├─ app.js              загрузка данных, адреса вида #/zanyatie/76, поиск, отметки «выполнено»
├─ vendor/katex/       формулы $...$ (локальная копия, чтобы работать без сети)
├─ manifest.webmanifest, sw.js, icons/   установка и работа без сети
```

## Данные (собирает site.py — руками не править)

| Файл | Что внутри |
|---|---|
| `data/index.json` | модули (название, цель, главы); занятия: номер, неделя, тема, модуль, главы, число задач; контрольные; входные тесты — для меню, сетки занятий и поиска |
| `data/z/NN.json` | занятие NN: что прочитать (страницы книги и PDF), повторение, входной тест перед занятием, примеры решений, задачи в порядке занятия: `n`, `id`, `level`, `type`, `cond`, `ans`, `sol` (Markdown с формулами) |
| `data/k/NN.json` | контрольная работа NN: критерий сдачи, время, задачи и для каждой — какой параграф повторить и в каких занятиях он шёл |
| `data/t/NN.json` | входной тест к главе NN — то же |
| `data/spravka.json` | обозначения, ступени, типы задач |

Задачи берутся из `src/data` в той же раскладке, что и документы `zanyatiya/` (`build.session_models`),
поэтому сайт и документы всегда совпадают: изменили задачу → пуш → занятия и сайт пересобраны.

## Поведение

- Поиск — по номеру занятия (префикс: «7» → 7, 70–79) и по словам из темы.
- Ответы и решения свёрнуты; переключатель «в конце / под задачей».
- Отметки «задача решена», «занятие выполнено», «работа выполнена» — только в `localStorage` этого браузера:
  зелёные плитки, ✓ и полоски «выполнено N из M» у модулей в меню. Прогресс никуда не отправляется.
